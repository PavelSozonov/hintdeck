# new — новинки из changelog

## new-send-now — Ctrl+Enter отправляет очередь сообщений немедленно
<!-- n: 138; since: 2.1.275; verified: 2.1.278 -->
Раньше поставленные в очередь сообщения ждали своего момента. Теперь `Ctrl+Enter` (или `Ctrl+X Ctrl+S`) прерывает текущий ход и отправляет всю очередь сразу. Отправленные и стоящие в очереди сообщения показываются серым, пока модель их не получит.

**Попробуй:** во время долгого хода набери уточнение, `Enter`, затем `Ctrl+Enter`.

## new-agents-md — Claude Code читает AGENTS.md, если в проекте нет CLAUDE.md
<!-- n: 139; since: 2.1.277; verified: 2.1.278 -->
В проекте без CLAUDE.md теперь подхватывается `AGENTS.md` — общий файл инструкций для разных кодовых агентов. Поведение меняется в `/config`, пункт «Project instructions». Если раньше ты держал CLAUDE.md-обёртку ради одного импорта AGENTS.md — она больше не нужна.

**Попробуй:** в репозитории с AGENTS.md проверь через `/context`, что файл загрузился.

## new-skills-sync — скиллы и плагины из аккаунта claude.ai приходят в терминал
<!-- n: 140; since: 2.1.275; verified: 2.1.278 -->
Скиллы и плагины, включённые в аккаунте claude.ai, теперь синхронизируются в терминальные сессии под тем же аккаунтом. Встроенные в такие скиллы shell-команды на твоей машине не выполняются. Отказаться: `"syncClaudeAiSkills": false` или `"syncClaudeAiPlugins": false` в настройках.

**Попробуй:** `/skills` — посмотри, какие скиллы пришли из аккаунта, и реши, нужны ли они в терминале.

## new-plugin-eval — claude plugin eval прогоняет набор проверок плагина
<!-- n: 141; since: 2.1.269; verified: 2.1.278 -->
`claude plugin eval` запускает eval-набор плагина против Claude Code и выдаёт оценки с воспроизводимыми результатами — JSON и HTML-отчёт. Начать: `claude plugin eval init`, справка — `claude plugin eval --help`. Это способ измерить, стал ли скилл лучше после правки, вместо оценки «на глаз».

**Попробуй:** `claude plugin eval --help`.

## new-max-effort-level — maxEffortLevel ограничивает потолок effort
<!-- n: 142; since: 2.1.267; verified: 2.1.278 -->
Настройка `maxEffortLevel` — на верхнем уровне или для конкретной модели внутри `modelSettings` — задаёт потолок уровня рассуждений у любого провайдера; уровень ниже выбрать по-прежнему можно. Страховка от случайно оставленного дорогого уровня.

**Попробуй:** реши, нужен ли тебе потолок для самой дорогой модели, и добавь `maxEffortLevel` в её `modelSettings`.

## new-time-format — формат времени в транскрипте настраивается
<!-- n: 143; since: 2.1.257; verified: 2.1.278 -->
Появились настройки «Time format» (`timeFormat`) и `timeZone`: 12- или 24-часовой формат, 24-часовой UTC либо свой шаблон strftime — для часов в конце хода и меток времени в транскрипте (`Ctrl+O`).

**Попробуй:** `/config` → Time format → 24-hour.

## new-config-mouse — в /config теперь работает мышь
<!-- n: 144; needs: fullscreen; since: 2.1.271; verified: 2.1.278 -->
В fullscreen-режиме панель `/config` понимает мышь: колесо прокручивает список, клик по значению меняет настройку, строка под курсором подсвечивается.

**Попробуй:** открой `/config` и поменяй любую настройку кликом.

## new-mcp-disconnect-notice — уведомление, когда MCP-сервер отвалился насовсем
<!-- n: 145; since: 2.1.273; verified: 2.1.278 -->
Если MCP-сервер отключился посреди сессии и автоматическое переподключение сдалось, Claude Code теперь показывает уведомление со ссылкой на `/mcp`. Раньше это было видно только по внезапно пропавшим инструментам.

**Попробуй:** увидев такое уведомление — `/mcp reconnect <сервер>`.

## new-plugin-install-marketplace — /plugin install умеет сам добавить marketplace
<!-- n: 146; since: 2.1.275; verified: 2.1.278 -->
`/plugin install <плагин> --marketplace <источник>` предлагает добавить marketplace перед установкой плагина — не нужно отдельно подключать его заранее.

**Попробуй:** при установке плагина из нового источника используй `--marketplace` одной командой.

## new-system-prompt-snapshot — --system-prompt-snapshot off для итераций над системным промптом
<!-- n: 147; since: 2.1.267; verified: 2.1.278 -->
По умолчанию разговор переиспользует системный промпт, записанный при первом запросе. `--system-prompt-snapshot off` пересобирает его на каждом запросе — удобно, когда подбираешь текст `--append-system-prompt` и продолжаешь тот же разговор через `--continue`.

**Попробуй:** `claude -c --append-system-prompt "<новая редакция>" --system-prompt-snapshot off`.
